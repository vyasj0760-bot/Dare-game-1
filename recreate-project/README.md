# Dare Game — Recreate Project

This is a separate, experimental Dare-only rebuild. It lives on the `recreate-dare-only` branch and does not replace the existing app on `main`.

## Design rules
- One dare = one small action.
- Clothing, chunni/dupatta, hairstyle, simple makeup, lipstick and accessories are separate tasks.
- Each category has a visual reference panel. The dupatta panel illustrates a boy wearing a dupatta; other categories currently use category-specific illustrated symbols.
- Skip is always allowed.
- Dark/light theme toggle.
- Credit shown in-app: **Designed by Maya's instructions**.

## Run
Open `index.html` in a browser. No build tools or server are required.

## Note
This is a prototype branch. Category illustrations are built-in vector artwork; individual custom reference photos/illustrations for every single dare can be added as the art pack is prepared.
